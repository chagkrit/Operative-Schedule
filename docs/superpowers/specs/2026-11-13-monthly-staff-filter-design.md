# ปฏิทินรายเดือน: ตัวกรองอาจารย์ + แก้เวลาล้นกล่อง (design สั้น)

สถานะ: รอเจ้าของอนุมัติ (2026-11-13). ยังไม่มีโค้ด.

## Intent / why
เจ้าของและอาจารย์ใช้ปฏิทินรายเดือนเพื่อ "หาวันว่างของอาจารย์" และ "ดูภาระงานรายเดือน" พร้อมกัน.

## Goals
1. เวลา `08:00–09:00` ไม่ล้นกล่อง `#N` ในรายการ "เคสที่ลงคิวแล้ว" (iPhone).
2. ปุ่มเลือกอาจารย์ (ทั้งหมด + อาจารย์ทีละคน) เหนือปฏิทิน; เมื่อเลือก:
   - ตัวเลขในแต่ละวัน = เคสของอาจารย์นั้น (นับจาก `bookings` ไม่ใช่ `days[].count`)
   - วันที่อาจารย์ไม่ว่าง (`staffUnavailability`) ขึ้นเครื่องหมายชัดเจน
   - วันที่ห้องเปิดแต่อาจารย์ว่างและไม่มีเคส = ช่องไม่มีตัวเลข
   - แถบสรุป: "อ.X · เดือนนี้ N เคส · ไม่ว่าง M วัน"
   - รายการ "เคสที่ลงคิวแล้ว" ของวันที่เลือก แสดงเฉพาะเคสของอาจารย์นั้น (หัวรายการแสดงจำนวนที่กรองแล้ว)
   - ส่วนสรุปห้อง (ลงแล้ว x/y ว่าง z) ยังเป็นภาพรวมของห้อง ไม่กรอง

## Non-goals / anti-goals
- ไม่เลือกหลายคนพร้อมกัน, ไม่ทำหน้าตารางอาจารย์×วันแยก, ไม่แก้ฝั่งเซิร์ฟเวอร์/API/DB.
- ห้ามทำให้ตัวเลขภาพรวมของห้องผิดเมื่อไม่ได้กรอง (ค่าเริ่มต้น "ทั้งหมด" = พฤติกรรมเดิมทุกอย่าง).

## Approaches
A) ปุ่มเลือกอาจารย์ทีละคน (เลือก) — ตรงกับการใช้งาน เปลี่ยนเล็ก ใช้ข้อมูลเดิม.
B) เลือกหลายคน — ตัวเลขกลายเป็นผลรวม เสียความหมายภาระงานรายคน.
C) หน้าตารางแยก — เกินคำขอ อ่านยากบนมือถือ.

## Calls ของ Claude (เจ้าของแก้ได้)
- state ตัวกรองเก็บใน `MonthlyCalendar` (ไม่จำข้ามการรีโหลด); รีเซ็ตเป็น "ทั้งหมด" เมื่อโหลดหน้าใหม่.
- ใช้รายชื่อ `STAFF` เดิม; สี/ฟอนต์/ระยะห่างตาม token เดิม (aurora.css) ไม่เพิ่มดีไซน์ใหม่.
- เวลาในกล่อง `#N` แสดง 2 บรรทัด (`08:00` / `–09:00`) และขยายความกว้างกล่อง.
- ตัวเลขวันที่นับเฉพาะเคสของอาจารย์นั้น ส่วนวันที่ปิดรับคิว/นอกช่วงยังคลิกไม่ได้เหมือนเดิม.
- เพิ่มเทสต์สำหรับตรรกะนับ/กรอง; ตรวจ `npm test`, `npx tsc --noEmit`, `npx eslint`; Opus review ก่อนเสนอ push.
